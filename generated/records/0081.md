## T4. Zeta half-plane

For the principal character modulo one, upstream `DirichletCharacter.LFunction_modOne_eq` identifies its \(L\)-function with `riemannZeta`. Thus \(\zeta(s)\ne0\) for \(\Re s>b_0\), \(s\ne1\). If a Lean statement includes the assigned value there, Mathlib's separate `riemannZeta_one_ne_zero` handles that convention; it is not an assertion that the analytic pole is removable.
